# Code of Conduct

Comic Pile is an open-source project, and its project spaces should be useful, welcoming, and safe for people who want to participate.

## Expected behavior

Participants are expected to:

- Treat other people with respect, even when disagreeing about code, product decisions, or priorities.
- Give feedback about the work rather than attacking the person doing it.
- Assume good intent while still being clear about mistakes, risks, and impact.
- Accept correction, take responsibility for mistakes, and help move discussions toward a useful outcome.
- Respect differences in experience, background, identity, communication style, and technical approach.

## Unacceptable behavior

The following behavior is not welcome in Comic Pile project spaces:

- Harassment, threats, intimidation, or sustained unwanted contact.
- Discriminatory or demeaning comments about a person or group.
- Personal attacks, insults, trolling, or deliberately inflammatory behavior.
- Sexualized language, imagery, or attention that is inappropriate for a professional project space.
- Publishing another person's private information without permission.
- Spam, impersonation, or other behavior intended to disrupt the project or its community.

## Scope

This Code of Conduct applies to participation in Comic Pile issues, pull requests, reviews, project discussions, and other spaces that are clearly associated with the project.

## Reporting and enforcement

If a concern can be discussed safely in public, bring it to the project maintainer in the relevant issue or pull request. For sensitive concerns, avoid posting personal or private details publicly and use the private contact options available through the maintainer's GitHub profile or GitHub's own abuse-reporting tools when appropriate.

The maintainer may edit or remove content, close or lock discussions, issue warnings, restrict participation, or block participants when necessary to protect the project and its community. Reports should be handled as privately and fairly as the available channel allows.

## Intent

This Code of Conduct is deliberately concise. It is informed by established open-source community standards, including the Contributor Covenant, while keeping the expectations and enforcement model specific to Comic Pile.
