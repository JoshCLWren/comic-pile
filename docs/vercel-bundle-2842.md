# Issue #2842 — Vercel Python bundle reduction evidence

## Mechanism verified
- `.vercelignore` is the supported exclusion mechanism for the existing `builds` (`@vercel/python`) deployment configuration. `vercel.json` `functions.excludeFiles` is not compatible with `builds` and is not used.
- Validated `vercel.json` remains unchanged from `main` (no `functions` block) and parses as JSON.

## Paths excluded (not imported by `api/index.py` at request time)
- `tests/**`, `tests_e2e/**` — test suites and fixtures
- `docs/**` — repository documentation (not read at runtime)
- `scripts/**`, `.github/**`, `.agents/**`, `prompts/**`, `.opencode/**` — automation/factory artifacts
- `alembic/` — DB migrations (run separately, not at request time)
- `coverage/`, `.coverage`, `htmlcov/`, `*.log` — coverage/lint artifacts
- `test-results/`, `playwright-report/`, `benchmarks/` — generated test outputs
- `*.dump`, `*.sql`, `*_backup_*.json`, `prod_backup*` — DB backups

## Intentionally retained for build correctness
- `frontend/src/`, `frontend/public/` are **not** excluded via global `.vercelignore` because the `@vercel/static-build` (`package.json` → `static/react`) requires those sources at build time. Excluding them globally would break the static build. Per-function exclusion is not available under the legacy `builds` API, so the Python function will still receive frontend sources; this is an accepted trade-off for build correctness. Future migration to Vercel `functions` config could enable per-function `excludeFiles` for `frontend/**`.
- `*.md`, `*.txt` blankets not used; `docs/` covers non-runtime docs without risking `pyproject.toml` or other needed files.

## Preserved production paths
- `api/index.py`, `app/`, `pyproject.toml`, `.env.example`, `static/react/` output (generated by static build, served via filesystem)

## Before / after (simulated file-count over repo walk, excluding `.git`)
- Before exclusions: ~1,844 files
- After `.vercelignore` exclusions: ~410 files (excluding `.git`)
- Excluded: ~1,434 files (tests, fixtures, docs, scripts, artifacts, coverage, backups)
- Note: counts exclude `frontend/src` which remains due to build dependency; actual after-count with frontend retained is ~620 files (still ~1,200 files excluded).

## Verification
- `vercel.json` validates as JSON and contains no incompatible `functions` key when `builds` is used.
- `api/index.py` import chain (`app.main.create_app`) does not import any excluded path.
- `scripts/check_markdown_docs.py` passes (no root allowlist violation).
- React/static deployment unchanged (`package.json` / `vercel.json` routes and `builds` preserved).
