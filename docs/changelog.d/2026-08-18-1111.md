## 2026-08-18

### Roll

- [#1111](https://github.com/JoshCLWren/comic-pile/pull/1111) adds "Set Current Issue" action to the Roll page action sheet for active pending threads with issue tracking. Users can now atomically correct the reading position by selecting a target issue number, which marks all earlier issues read, sets the target as current/unread, updates `threads.next_unread_issue_id`, and pins `session.pending_issue_id` so the corrected issue appears immediately in the rating view without a cancel/Queue/Read Now workaround.
