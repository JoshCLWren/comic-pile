# Issue #926 Plan: Add parallel lanes to continuity plans

## Scope
Update the frontend continuity planner (`ContinuityPlannerPage`) to support parallel lanes for informational continuity plans. The backend (`continuity_plan` model/API) already supports `lanes_json` and `nodes_json` with lanes and compiles no rules in informational mode, so no backend changes are required.

## Key files
- `frontend/src/pages/ContinuityPlannerPage.tsx` — main planner with lane management
- `frontend/src/services/api-continuity-plans.ts` — already supports lanes
- `tests/test_continuity_plan_api.py` — add focused test for parallel lane behavior
- `frontend/src/test/continuity-projection.spec.ts` — extend with lane-related E2E

## Implementation steps
1. Update planner page to manage lanes array instead of hard-coded `LANE_ID`/`main`
2. Change default ordering mode to `informational` so parallel lanes are allowed
3. Add UI for adding, renaming, deleting, and reordering lanes
4. Organize nodes by lane; show mobile lane switcher
5. Allow moving nodes between lanes by updating `lane_id`
6. Ensure empty lanes persist and deleting lanes with members is prevented (via payload validation which already exists)
7. Update `toPayload` to include lanes and set nodes' lane_ids correctly
8. Add focused Chromium Playwright coverage

## Verification commands
- `pytest tests/test_continuity_plan_api.py -v`
- `cd frontend && pnpm run build && pnpm run test`
