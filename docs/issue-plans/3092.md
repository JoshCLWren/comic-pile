# Issue #3092: Creator insights 6/8 - surface strongest and weakest work on creator detail

## Goal
Add concise evidence-backed summaries to creator detail pages showing:
- Highest-rated series/thread
- Lowest-rated series/thread
- Most-rated series/thread
- Highest-rated individual issues
- Lowest-rated individual issues

## Acceptance Criteria
- [x] Creator detail surfaces strongest, weakest, and most-read series/thread context when sample requirements are met
- [x] Individual highest/lowest rated issues are clearly distinguished from aggregate series conclusions
- [x] Minimum-sample behavior is documented and tested
- [x] Ties are deterministic
- [x] Every conclusion can drill into supporting series/issues
- [x] Partial creator metadata is not presented as exhaustive evidence
- [x] Mobile layout remains compact and useful

response wiring, frontend types/hook/page highlights section, regenerated OpenAPI
artifacts, and backend + frontend tests. Series highlights require a minimum of three
rated issues and complete creator metadata; individual issue extremes are labeled
separately and capped at three per direction.

### Minimum Sample Thresholds

Based on the requirements:
- **Series insights**: Minimum 3 rated issues in a series to qualify for "strongest", "weakest", or "most-rated"
  - This prevents a single 5★ issue from automatically beating a long consistently loved run
- **Individual issue insights**: No minimum (show if data exists)
  - One-off ratings are allowed but labeled as individual issues, not "best work"
  - Top 3 highest-rated and lowest-rated issues shown

### Deterministic Tie-Breaking

For all insights:
1. Primary sort by the metric (rating, count, etc.)
2. Secondary sort by series_key (lexicographic)
3. Tertiary sort by thread_id (numeric)
4. Quaternary sort by issue_id (numeric)

This ensures consistent ordering across requests.

### Sample Threshold Warnings

When insights are shown but the sample is below a meaningful threshold:
- Show warning text: "Minimum sample: X rated issues required for series comparisons"
- Individual issues have no minimum threshold

### Partial Metadata Handling

Series insights exclude series where `metadata_complete=False` to avoid presenting partial data as exhaustive evidence.
