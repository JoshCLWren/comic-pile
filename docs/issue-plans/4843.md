# Issue #4843: MIGRATE: issue-identity (non-preview) + CBL adoption browser-called routes to Rust v2

## Overview

This issue addresses the migration of 12 browser-called API operations from Python FastAPI to native Rust v2. These operations are currently implemented under the `/api/v1/issue-identity/` and `/api/v1/cbl/` prefixes.

## Problem Statement

**Current Status:**
- 42 total API operations in the system
- 41 operations are already implemented in native Rust
- Only 1 operation remains in Python FastAPI (orphaned)
- The 12 operations to migrate are currently implemented in Python:
  - `app/api/issue_identity.py` - handles `/api/v1/issue-identity/` operations
  - `app/api/cbl_sources.py` - handles `/api/v1/cbl/` and `/api/v1/issue-identity/cbl/` operations

**Operations to Migrate (12 total):**

### Issue Identity Operations (10 operations):
1. `GET /api/v1/issue-identity/cbl-sources` - CBL source list discovery
2. `GET /api/v1/issue-identity/cbl-sources/browse` - Browse CBL catalog
3. `GET /api/v1/issue-identity/cbl-sources/by-comicvine-issue/{comicvine_issue_id}` - Search by comicvine issue
4. `POST /api/v1/issue-identity/cbl-sources/compare` - Compare sources
5. `GET /api/v1/issue-identity/cbl-sources/folders` - List folders
6. `GET /api/v1/issue-identity/cbl-sources/{list_id}` - Get specific CBL source list
7. `POST /api/v1/issue-identity/cbl/{list_id}/adoption-plan` - Calculate dry-run adoption plan
8. `GET /api/v1/issue-identity/cbl/{list_id}/adoption-preview` - Preview dry-run adoption
9. `POST /api/v1/issue-identity/cbl/{list_id}/reading-graph-preview` - Preview reading graph
10. `GET /api/v1/issue-identity/reading-lists/{list_id}/cbl-candidates` - Get CBL candidates

### CBL Operations (2 operations):
11. `POST /api/v1/cbl/{list_id}/adoption-commit` - Commit adoption (claim CBL source list)
12. `POST /api/v1/cbl/{list_id}/reading-plans/{plan_id}/adoption-commit` - Adopt specific plan
