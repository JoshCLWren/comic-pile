# Issue #3828 Plan: Cooldown live OpenCode free models that fail exact smoke as unavailable

## Problem
Factory 45 selected `opencode/ll-alpha-free` from 12 live catalog entries, but bounded exact-model smoke failed with `Error: Model unavailable: opencode/ll-alpha-free`. The live selector does not exclude demonstrably non-invokable models. Subsequent successful worker attempts overwrite earlier attempt records, so evidence must be durable and model-specific.

## Acceptance Criteria
1. **Exact smoke failure classification**: When the OpenCode smoke test fails with "Model unavailable", classify it as `model_unavailable` (not `provider_failure` or `unknown_failure`).
2. **Durable attempt records**: Persist the selected model, evidence run, timestamp, and outcome in existing `factory-discovery-outcome` / trusted #1093 attempt comments.
3. **Trusted-record filtering**: Live selector consults only authenticated/trusted registry attempt comments, rejects forged/untrusted/malformed/stale records.
4. **Cooldown mechanism**: Temporarily exclude unavailable models using a bounded cooldown (6 hours). Automatically retry eligibility after expiry.
5. **Free-only selection**: Keep OpenCode 2 unpinned, select dynamically from live *provably free* catalog, retain `opencode/big-pickle` eligibility, bound smoke duration.
6. **Regression tests**: Add tests covering exact error classification, trusted-record filtering, cooldown and expiry, all-candidates-unavailable behavior, and free-only selection.

## Implementation Steps

### 1. Modify `.github/scripts/factory_live_opencode.py`

**Add model cooldown tracking:**
- Create a `ModelCooldown` dataclass to track model, expiry timestamp, and reason
- Add a `CooldownRegistry` class to manage cooldowns across runs
- Load cooldowns from a persistent file (e.g., `RUNNER_TEMP/factory-model-cooldowns.json`)

**Add smoke failure classification:**
- Modify the smoke test runner to detect "Model unavailable" errors
- Classify failures as `model_unavailable` with model-specific evidence
- Write to `factory-discovery-outcome` with model and timestamp

**Add trusted-record filtering:**
- Parse trusted comments from registry #1093
- Extract model outcome evidence from trusted comments
- Filter out untrusted/malformed/stale records

**Add cooldown logic:**
- Before selecting a model, check if it's in cooldown
- If in cooldown, skip and rotate to next candidate
- After smoke test completes (success or failure), update cooldown if needed
- Cooldown duration: 6 hours (21600 seconds)

**Add automatic retry after expiry:**
- On next selection attempt, check cooldown expiry
- If expired, remove from cooldown and retry selection

### 2. Add tests to `tests/test_factory_live_opencode.py`

**Test exact error classification:**
- Test that "Model unavailable" smoke failures are classified as `model_unavailable`
- Test that other failures are classified differently

**Test trusted-record filtering:**
- Test that untrusted comments are ignored
- Test that malformed comments are ignored
- Test that stale comments are ignored

**Test cooldown and expiry:**
- Test that unavailable models are skipped during cooldown
- Test that models are automatically re-probed after expiry
- Test that cooldown is persisted across runs

**Test all-candidates-unavailable behavior:**
- Test that when all candidates are unavailable, the selector raises an error
- Test that the error message includes the unavailable models

**Test free-only selection:**
- Test that only zero-cost models are selected
- Test that `big-pickle` is always eligible
- Test that paid models are never selected

### 3. Add tests to `tests/test_factory_executor_selection_workflow.py`

**Test smoke failure classification in workflow:**
- Test that `model_unavailable` outcome is written for exact smoke failures
- Test that the outcome includes model and timestamp

**Test cooldown integration:**
- Test that workflow respects cooldowns when selecting candidates
- Test that cooldowns are persisted and reloaded
