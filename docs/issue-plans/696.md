# Epic #696 — Incremental Queue pagination

## Contract

- Queue initially fetches one bounded page (page_size=50, max 200).
- Search and all retained sorts (`position`, `title`, `created`) remain correct across pages with deterministic tie-breakers (`id` ascending/descending as required).
- Later pages load without duplicates or gaps (keyset pagination via opaque cursor).
- Mutations (`create`, `edit`, `reposition`, `delete`, `snooze`) do not redownload the complete library; pagination resets cleanly to the first compatible page.
- Initial request count, payload, rendering, and memory remain bounded at 5,000 threads.
- Retired `collection_id` parameter is rejected (`422`).
