# Issue #1732 Plan: Reading-mode selector sheet for bandwidth and intent

## Target
Issue #1732 — Phase 5: add reading-mode selector sheet for bandwidth and intent.
Part of epic #1685. Depends on #1729 (manual session-mode API) and #1730 (mode in bootstrap).

## Contract
- Small modal/bottom sheet with two independent groups:
  - Bandwidth: Light · Balanced · Deep
  - Intent: Balanced · Momentum · Familiar · Explore · Random
- Submit through canonical session-mode API.
- Reflect active values and pending/error state.
- Changing one dimension must not reset the other.
- Brief explanation for Random (unweighted legacy-style selection within current die pool).
- Close cleanly after successful update; refresh/synchronize bootstrap state.
- Accessible keyboard focus, Escape/close, touch behavior.
- Rendered tests cover desktop/mobile and API failure.
