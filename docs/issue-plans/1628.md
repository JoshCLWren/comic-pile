## 6. Implementation steps (closure-critical only)

1. **Defect 1 (multi-match):** In `_run_series_resolution`, when `len(identities) > 1`, do NOT confirm; instead persist a candidate mapping at reduced confidence (or skip confirmation). The AC says ambiguous matches must remain candidate/unresolved — implement as: if >1 identity, return without creating a confirmed mapping, or create `candidate` status mapping. Per AC: "persists a candidate/unresolved state instead of auto-confirming". We'll create a `candidate` mapping for the top match with 0.55 confidence and leave others as unresolved, but simpler: skip confirmation entirely for ambiguous cases (log ambiguous) since AC says must not auto-confirm. We'll read existing behavior: currently confirms `identities[0]` at 0.55. We'll change to: if `len(identities) > 1`, log ambiguous and return without creating any confirmed mapping; if exactly 1, confirm.
2. **Defect 4 (unguarded task):** Wrap `_run_series_resolution` body in a broad `try/except` catching `Exception` and logging it, mirroring `refresh_issue_metadata`. No unretrieved exceptions escape.
3. **Defect 5 (pagination cap + multiple rows):**
   - Add `max_offset` / page cap in `_resolve_issue_from_series` (`offset < max_pages * limit` or cap pages).
   - Hard `_find_existing_mapping` against `MultipleResultsFound` by using `.limit(1)` on the query or catching exception and returning `None`.
4. **Defect 2 (Phase 2 backfill):** Repair `reconcile_unmapped_issues` in `app/services/catalog.py`:
   - Prioritize: active `next_unread_issue_id` threads first, then other unread in threads with confirmed series, then threads needing series resolution.
   - Report counts: confirmed, candidate, unresolved, skipped.
   - Make idempotent on rerun (use existing mappings, don't duplicate pseudo-identities).
   - Remove the `comicvine-{issue_number}` pseudo-identity fabrication (line 254). Instead, look up actual ComicVine identity by issue number or skip.
5. **Defect 3 (Phase 3 scope):** Phase 3 (`comicvine_identity_repair`) is pre-existing dead code with no production callers. Per AC: "Wire or consciously scope out Phase 3 conservative series resolution; if scoped out, document". We'll scope out by adding a comment in `app/comicvine_identity_repair.py` noting it is out of scope for #1628 and linking to parent epic #1555, and not wire any new callers.

## 7. Tests
