# Issue 1644 Plan — Queue position ordering ignores dependency feasibility

## Contract choice (documented)

**Option (a): feasible-only ordering.** Blocked threads sink below all readable (unblocked) active threads in the queue display, preserving user-controlled position within each feasibility group. This directly resolves the contradiction between queue position and roll eligibility.

Related blocker-explanations issue (#698) covers the inline explanation rendering needed for option (b); this issue selects (a) and does not depend on #698.
