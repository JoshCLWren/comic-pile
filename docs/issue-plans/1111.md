# Issue 1111: Atomic Current Issue Correction

## Goal
Enable atomic correction of the current reading issue from an active Roll session.

## API Change
Create `POST /api/v1/threads/{thread_id}/issues:set-current`

### Request Body
```json
{
  "issue_id": int
}
```

### Logic
1.  Lock thread and all issues.
2.  Find target issue position.
3.  For all issues:
    - If `position < target_position`: `status = 'read'`, `read_at = now()`.
    - If `position >= target_position`: `status = 'unread'`, `read_at = None`.
4.  Update thread:
    - `next_unread_issue_id = target_issue_id`
    - `issues_remaining` recalculated.
    - `reading_progress` updated.
    - `status` updated if needed.
5.  Update active session if pending_thread_id matches thread_id:
    - `pending_issue_id = target_issue_id`

## Frontend Change
1.  Add `set-current` action to `RollPage` or a new component.
2.  The preferred UX is an in-context issue picker (perhaps a dropdown or list of unread issues) on the active Roll state.
3.  Ensure the Roll view refreshes to show the updated active issue.

## Verification
- Unit/API tests for `set-current` endpoint (forward and backward correction).
- Chromium E2E test to reproduce the scenario.
