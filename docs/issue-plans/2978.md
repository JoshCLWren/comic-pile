# Issue 2978 Plan — Cheapen Python Fluid cold imports

## Contract
- `app/api/__init__.py` stops eagerly importing the full router surface.
- `/api/ping` (and metrics) register without loading core/heavy API modules.
- Core/heavy routers remain available for real traffic (lazy register or safe split).
- Remove/neutralize duplicate `create_app()` on Vercel entry path (`api/index.py`).
- Existing routes + tests pass.

## Files
- `app/api/__init__.py`
- `app/main.py`
- `api/index.py`
- `tests/test_ping_cold_start.py` (add regression evidence)

## Approach
1. Make `app/api/__init__.py` lazy: remove eager submodule imports and router patches; defer them to a function called only when needed, or keep `__all__` but import lazily.
2. Modify `create_app()` or `register_all_routers()` so lightweight routes (ping, metrics) can be registered separately from core/heavy routes.
3. In `api/index.py`, avoid second `create_app()` by importing existing `app` from `app.main` or making the module-level `create_app()` conditional.
