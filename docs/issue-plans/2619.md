# Issue #2619: Deduplicate reader-order / universe production migration service scaffolding

## Problem
Six services share near-copied dry-run/apply scaffolding and helper idioms:

- `source_backed_reader_order_migration.py` (976)
- `explicit_reader_order_migration.py` (1226)
- `ultimate_universe_production_migration.py` (~1553)
- `bprd_production_migration.py` (~1025)
- `legacy_reading_order_production_migration.py` (~1246)
- `reader_order_migration_coordinator.py` (1017)

Duplicated idioms:
- `_require_clean` / `_require_snapshot` / `_require_reviewed_snapshot` clean-gate checks (3 variants, 2 copies of `_require_clean`)
- `_invalidate_continuity_snapshot` + `_get_blocked_thread_ids_uncached` + `refresh_user_blocked_status` + `get_roll_pool` blocked-refresh sequences (repeated per dry-run and apply)
- `cast(int, ...)` / `int(cast(int, row["id"]))` safe-id coercion clusters (90+ sites) with `Any` payloads
- `_stable_hash` / `_json_value` / `_plan_fingerprint` / `_plan_fingerprint_from_payload` / `_rules_fingerprint` / `_rule_snapshot` / `_dep` / `_dependency_id_batches` utilities copied between ultimate, bprd, legacy, source_backed, explicit

Heavy `Any` + redundant `cast` clusters create `ty` `redundant-cast` and `ANN401` pressure.

## Current Flow
Each migration:
1. Defines own `MigrationInvariantError` (3 copies) + `_stable_hash` / `_json_value` (3 copies) + gate helpers (`_require_clean` 2 copies, `_require_snapshot` etc.)
2. In dry-run: calls `_invalidate_continuity_snapshot(user_id, db)`, then later `await _get_blocked_thread_ids_uncached` + `await get_roll_pool` to prove eligibility parity, with inline `cast(int, ...)` for every snapshot row id.
3. In apply: repeats snapshot-token check, dependency delete with batched `delete(Dependency).where(Dependency.id.in_(...))`, `await refresh_user_blocked_status`, `await db.flush()`, fingerprint checks, and guarded `cast(int, ...)` reads of `snapshot["planned"]...`.
4. Coordinator re-imports `MigrationInvariantError` and several `_helpers` from `ultimate_universe` and `explicit`, creating cross-service coupling.

## Target Architecture

### `app/services/migration_shared.py` (new)
Single ownership for shared scaffolding:

- `MigrationInvariantError` — one canonical exception (others import it)
- `stable_hash(value: object) -> str` + `json_value(value: object) -> object` — one stable-hash implementation
- `dependency_id_batches(ids: set[int] | list[int]) -> tuple[tuple[int,...],...]` — one batch helper (replaces local `_dependency_id_batches`)
- `dep_snapshot(dependency: Dependency) -> dict[str, object]` + `rule_snapshot(rule: ContinuityRule) -> dict[str, object]` — shared row snapshots
- `plan_fingerprint(plan: ContinuityPlan) -> str` + `plan_fingerprint_from_payload(payload: dict[str, object]) -> str` + `rules_fingerprint(rules: list[ContinuityRule]) -> str` + `rule_descriptor(rule: ContinuityRule) -> dict[str, object]` — one fingerprint family
- Snapshot gates:
  - `require_clean_snapshot(snapshot: dict[str, object]) -> None` — validates `ok is True` and `snapshot_token` str, raises `MigrationInvariantError` (replaces `_require_clean`)
  - `require_snapshot_token(snapshot: dict[str, object]) -> str` — returns token or raises (replaces `_require_snapshot` / `_require_reviewed_snapshot`)
  - `require_reviewed_snapshot(snapshot, ...)` wrapper when needed
- Blocked refresh helpers:
  - `invalidate_continuity_snapshot(user_id: int, db: AsyncSession) -> None` — thin re-export/wrapper
  - `async def current_roll_eligibility(user_id: int, db: AsyncSession, affected_ids: set[int]) -> tuple[set[int], set[int], list[int]]` — encapsulates `_get_blocked_thread_ids_uncached` + `get_roll_pool` + eligibility parity check, or at minimum `async def refresh_blocked_status(user_id, db)` helper that wraps `refresh_user_blocked_status` + `flush`
- Safe id coercion:
  - `def coerce_int(value: object, *, label: str = "value") -> int` — validates `isinstance(value,int) and not bool`, raises `MigrationInvariantError` otherwise; replaces `int(cast(int, x))`
  - `def coerce_int_from_mapping(mapping: dict[str, object], key: str) -> int` — typed helper for `snapshot["planned"]` keyed reads
  - `def coerce_ints(values: list[object]) -> list[int]` — batch helper
  - Replaces `cast(int, ...)` without introducing `cast`

### Service modifications (all six)
- Import `MigrationInvariantError`, `stable_hash`, `json_value`, gate helpers, id-coercion helpers, batch helper, snapshot helpers from `migration_shared`
- Delete local duplicates of those helpers
- Replace `int(cast(int, row["id"]))` etc with `coerce_int(row["id"])` or `coerce_int_from_mapping(row, "id")`
- Replace `_require_clean(snapshot)` with `require_clean_snapshot(snapshot)`
- Replace `_require_snapshot` / `_require_reviewed_snapshot` with `require_snapshot_token`
- Replace `cast(int, thread.next_unread_issue_id)` with `coerce_int(thread.next_unread_issue_id)` or preserve `cast` only where narrowing already proven to `ty`, but prefer helper
- Keep behavior identical: hash outputs, error messages, and eligibility proofs unchanged; snapshot tokens remain stable because `stable_hash` is identical implementation

## Risks
- Snapshot token stability: `stable_hash` must stay byte-identical (json dumps sort_keys, separators, default). Shared impl copies ultimate's exactly.
- Fingerprint compatibility: `plan_fingerprint` must match persisted plan rows for rollback guard tokens. Keep field order identical.
- `cast` removal must not introduce `ty` errors: helper returns `int` without `cast`, satisfying `ty` without `redundant-cast`.
- Circular imports: `migration_shared` must not import from migration services that import from it. Keep it leaf-level (only models, sqlalchemy, json, hashlib, typing).
