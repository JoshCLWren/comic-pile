# Issue #3605 — Queue: show verified year, volume, and publisher on every series row

## Contract (from issue body)
- Each Queue Series row keeps the series title as primary label and shows secondary metadata consistently: publication/start year, volume/run label when known, publisher.
- Reuse stored canonical ComicVine/confirmed catalog metadata only; no fabricated values.
- Truthful fallbacks: `Unmapped series`, `Year unknown`, `Volume unknown`.
- Data comes from the reader-owned Thread's confirmed identity (batched), never a guessed title lookup or per-row provider request.
- No production data mutation; read-only display change.

- `app/services/thread_service.py` — extract series metadata from confirmed series identity metadata (batched via `fetch_confirmed_series_identity_metadata`); pass into `to_queue_list_item` for queue/completed/excluded list paths.
- `frontend/src/generated/openapi.json` + `openapi.ts` — add the three fields to `QueueThreadListItem` (hand-kept consistent; codegen unavailable locally).
- `frontend/src/pages/QueuePage/QueueThreadCard.tsx` — render year · volume · publisher under title with fallbacks and accessible labeling.
- Tests: backend pytest for series metadata extraction/queue list; frontend vitest for card rendering.
