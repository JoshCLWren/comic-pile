# Issue #3217 — DB scale 01: add a read-only storage, index, and query census

Plan version: 1. Frozen contract per issue body.

## Implementation steps
1. Create `scripts/db_census.py`: async read-only command, synthetic fixtures (2/100 users, small/large libraries, mixed legacy/delta snapshots, shared provider identities), inventory table/index/TOAST sizes, overlapping index detection, snapshot payload distribution, bounded EXPLAIN plans, deterministic JSON report (`docs/census-report-v1.json`).
2. Read-only enforcement: begin with `SET TRANSACTION READ ONLY`, `SET statement_timeout = '5s'`; reject mutation flags; never EXPLAIN ANALYZE writes.
3. Redaction: strip user names, titles, notes, payload content, credentials; keep only structural counts/bytes/plans.
4. Tests: `tests/test_db_census.py` covers read-only behavior, mutation rejection, redaction (no payload leakage), fixture completeness, JSON schema, bounded query plans.
5. Verification: `python scripts/db_census.py --output docs/census-report-v1.json` with synthetic DB; inspect artifact.

## Risks / boundaries
- Synthetic/local data only; no production DB mutation.
- Async PostgreSQL only (`asyncpg`).
- No app behavior changes; no frontend changes.
- Preserve existing schema (reading session naming, thread format retirement #3035).
