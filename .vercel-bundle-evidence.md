- `.vercelignore` is the supported exclusion mechanism for the existing `builds` (`@vercel/python`) deployment configuration.
- `vercel.json` also receives an explicit `functions.api/index.py.excludeFiles` entry for visibility.

- `test-results/`, `playwright-report/`, `benchmarks/` — generated test outputs
- `*.dump`, `*.sql`, `*_backup_*.json`, `prod_backup*` — DB backups

## Preserved production paths
- `api/index.py`, `app/`, `requirements*.txt`, `.env.example`, `static/react/` (static build emits separately)
